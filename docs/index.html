日本・沖縄

気象庁やNHKによりますと8日未明、静岡県西部を震源とするマグニチュード5.7、深さ約41キロメートルの地震が発生し、愛知県知多市で最大震度5強を観測したほか、長野、岐阜、静岡、愛知の4県で震度5弱を記録しました。東海道新幹線が一部徐行したほか20名以上の軽傷が確認されましたが、気象庁は南海トラフのプレート固着状態に特段の変化はないと説明しています。 QAB琉球朝日放送によりますと米四軍調整官は、海兵隊員による強盗殺人事件を受けた30日間の反省期間終了に伴い、夜間外出規制を12月7日まで1カ月延長すると発表しました。伍長以下の下士官や兵卒を対象に午前0時から5時の外出を禁止し、全階級で午前0時以降の基地外や自宅外での飲酒を禁じます。一方で軍曹以上の規制解除に対する県民世論の反発も予想されています。
