日本・沖縄

NHKによりますと、高市政権のもとで注目されていた食料品の消費税減税に関する関連法案が、20日午後の衆議院本会議で実質的な審議に入りました。高市首相は物価高に苦しむ家計支援のため法案の早期成立を目指す姿勢を表明しています。野党との活発な議論が交わされる見通しで、法案の成立時期に強い関心が集まっています。 沖縄タイムスなどによりますと、猛烈な勢力の台風30号が先島諸島方面へ接近する見込みとなったため、23日から奥武山公園で開催予定だった第50回沖縄の産業まつりの全日程中止が決定しました。30万人以上の来場を見込んでいた大規模イベントの中止は2017年以来2度目です。また、久米島便フェリーなどの事前欠航も決定しています。

世界情勢・2つの視点

ロイター通信などによりますと、イエメンの反政府勢力フーシ派がサウジアラビアの石油および軍事関連施設へ複数回の攻撃を実施したと表明しました。ホルムズ海峡を含めた原油輸送路のリスクが高まり、原油急騰を招いています。一方、欧州ではフランスで予算案を巡る暴動が発生し、国債利回り急上昇とユーロ安の要因となっています。 食料品の消費税減税を支持する立場からは、長期化する物価高や原油高に対して家計負担を直接軽減し、個人消費を底上げする即効性のある経済対策として早期成立が強く期待されています。 一方で米国のベッセント財務長官などが指摘するように、日本の拡張的な財政運営が長期金利の上昇や円安圧力を再燃させ、輸入インフレをかえって加速させるリスクがあるとの批判も出ています。
