日本・沖縄

外務省によりますと、高市首相とベトナムのトー・ラム共産党書記長兼国家主席が迎賓館で会談しました。重要鉱物サプライチェーンの協力加速やAIおよび半導体分野での連携強化、防衛装備品を無償供与する政府安全保障能力強化支援の早期機材供与で合意しました。あわせてベトナム産かんきつ類のポメロと日本産ブドウの相互輸入解禁も申し合わせています。 琉球朝日放送によりますと、那覇空港で訪日外国人向けの免税手続きを出国時の税関確認後に消費税を還付するリファンド方式へ完全移行するための専用端末整備が進んでいます。免税品の国内での不正転売を防いで消費税収を適正化するとともに、空港出発ロビーの混雑を緩和し、訪日客の利便性向上を図る狙いがあります。

世界情勢・2つの視点

国連気候変動枠組条約事務局によりますと、第31回締約国会議COP31がトルコのアンタルヤで開幕しました。会期は11月20日までで、トルコとオーストラリアの共同議長体制で運営されます。約束の確実な履行を掲げ、2035年に向けた各国の温室効果ガス削減目標や気候資金支援の枠組みが主な焦点となります。 生成AIや物理世界を動かすフィジカルAIの実装は、製造や物流、医療現場での人手不足を根本から解決する構造改革であり、足元で行われているインフラ投資は将来の生産性を左右する不可欠な成長原資であるとする見解があります。 データセンターの電力制約や燃料費、重要鉱物の調達コストが増加する一方で、巨額の設備投資に見合う収益化が短期的に達成できておらず、高評価銘柄の調整リスクや金融市場の不安定化を警戒する見解もあります。
