世界情勢・2つの視点

米国市場では八月の貿易赤字拡大を受けて長期金利指標の十年国債利回りが一時五点三五パーセントと二十四年ぶりの高水準を記録しました。その後に実施された三百九十億ドル規模の国債入札が好調に消化されたことで利回りの急騰は一服したものの、依然として五点三パーセント前後で高止まりしています。連邦準備制度理事会の追加利上げ姿勢を巡り市場では緊張が続いています。 一つ目の視点として、人工知能データセンター向けの電力やインフラ需要の急拡大や、新関税導入に伴う輸入コストの上昇がインフレ圧力を再燃させており、連邦準備制度理事会は年内追加利上げの姿勢を崩せず金利高止まりが続くという見方があります。 もう一つの視点として、巨額の貿易赤字による国内総生産の下振れ懸念や借入コストの上昇に伴う個人消費の鈍化が見られ、過度な追加引き締めは景気後退を招くため金利の上昇は頭打ちになるという見方があります。
