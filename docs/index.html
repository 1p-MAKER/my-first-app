日本・沖縄

読売新聞などの報道によりますと、十一月一日から訪日外国人向けの消費税免税制度が抜本的に見直され、店頭での即時免税から空港や港湾での出国時還付方式に移行しました。転売目的の不正購入を防ぎ、税の公平性を確保する狙いがあります。一方で、制度移行に伴う空港窓口の混雑や店舗側の案内負担の増加、インバウンド消費の一時的な減速を懸念する声も出ています。 沖縄県警の発表によりますと、十月三十一日未明、沖縄市内で米海兵隊の伍長が基準値の二倍を超えるアルコールが検出され、酒気帯び運転の疑いで現行犯逮捕されました。十月の女性強盗殺人事件を受けた夜間外出禁止令の最中の事案で、県民の反発が強まっています。一方、時事通信によりますと、二〇一九年の火災から七年を迎えた首里城正殿の復元が完了し、十一月二十三日の一般公開に向けた最終調整が進んでいます。
